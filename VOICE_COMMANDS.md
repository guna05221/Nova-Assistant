# Nova voice commands (current starter)

- "Hey Nova" — wake phrase (after adding Vosk model)
- "Open YouTube" — launch matching installed app when visible to package manager
- "Open Settings" — Android settings
- "Search online for Java Spring Boot" — open Google search
- "Look up free AI video tools" — open Google search
- "Scroll down" / "Scroll up" — accessibility gesture, if enabled
- "Go back" / "Go home" — accessibility global actions
- "Write a YouTube description for a funny video" — share a writing prompt to an app you choose

Search currently opens browser results; it does not summarize web pages. Writing is a prompt handoff, not built-in AI generation.
